# Artbot ESP32 Code 

This is the code that was flashed to the ESP32-S3 and controlled the functionality of the drawing robot my team built as our senior design project. The robot was a group effort with each of us contributing our own sections. I was responsible for the Android app and parts of the main code on the ESP32 that provided wifi connection and communicated with the Android app.

We won "Best Project - Faculty Choice" for our project.
